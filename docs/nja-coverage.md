### 分類ごとの所見

**A** — 113件（A の11.3%）で建物名・階が `other` に残る。
例: `" NSセントラルパークビル1階"`, `" フォンテーヌブロー 103号室"`, `" 大地屋ビル 3FB"`

**B** — 153件中150件（98%）で `other` が数字で始まり、番地が残っている。
町字の `rsdt` フラグから街区符号方式であることは確定できるが、建物名が混在する。

| 入力 | `other` |
| --- | --- |
| `秋田県秋田市山王五丁目１０－２８　はりまビル` | `"10-28 はりまビル"` |
| `大阪府大阪市城東区野江４－１－８－１０２` | `"1-8-102"` |
| `東京都東村山市栄町３－１８－１８　池田ビルⅢ　１階` | `"18-18 池田ビルⅢ 1階"` |
| `千葉県東金市日吉台４－３－２エスタシオＢ` | `"3-2エスタシオB"` |

**E** — `神奈川県横浜市旭区二俣川` のように丁目なしの町字が存在しないケース、
および `静岡県焼津市…`（焼津市の誤記＝正しくは焼津市だが県名と不整合）のような入力側の誤り。

## その他の所見

- **支号（`rsdt_num2`）は A の428件中0件**。`housenumber` の `-` 連結は実データではまず出現しない。
- **入力データの座標が `0.0` のレコードが12.7%**。NJA は代表点を返すため補完可能（精度 level つき）。
- 入力データ自体の誤りもある: `東京都三鷹市下連雀三鷹市下連雀３－３３－１７`（市名重複）、
  `長野県松本市寿南１ー２５４ー１`（区切りが長音符 U+30FC）。後者は NJA が正規化できている。

## 告示の数字表記が復元できる範囲

`oaza_cho_k`（カナ）が告示の数字表記を保持している。

| 自治体 | 大字に漢数字を含む | うちカナが算用数字 |
| --- | --- | --- |
| 札幌市中央区 | 920 | 920 (100%) |
| 帯広市 | 1454 | 1372 (94%) |
| 旭川市 | 2475 | 2359 (95%) |

判別は正確: `北十条西`→`キタ１０ジョウニシ`（算用告示）に対し、
`八千代町`→`ヤチヨチョウ`、`住吉町一条`→`スミヨシチヨウイチジヨウ`（漢数字告示）。

**一方 `chome` は ABR データ自体が常に漢数字**で、告示表記は上流に存在しない。
流山市江戸川台西（表は `4丁目` を期待）も ABR では `chome: "一丁目"`。
「丁」と「丁目」の区別のみ `chome` が保持している（堺市 = `一丁`）。
