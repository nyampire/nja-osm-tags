# NJA の番地解決カバレッジ（実データ計測）

計測スクリプトは [scripts/measure-coverage.ts](../scripts/measure-coverage.ts)。

```bash
node scripts/measure-coverage.ts
```

seed 固定の線形合同法でサンプリングするので、同じ入力ファイルなら再実行で同じ集合を引く。
入力は `sample/05_pharmacy_20260601.csv`（容量が大きいため gitignore してある）。
ネットワークを使い、1000件で20分前後かかる。

## 対象データ

厚労省の薬局オープンデータ。
61,398件、128列、UTF-8 BOM 付き。
住所は `所在地` 列。

## NJA 実行結果（ランダム1000件）

ファイル先頭からのランダムサンプル。

| B 住居表示実施済みだが明細なし | 153 | 15.3% |
| C 地番方式（ライセンス上の対象外） | 318 | 31.8% |
| D 町字は特定できたが番地体系不明 | 94 | 9.4% |

`level` の分布は 8 が746件、3 が247件、2 が7件。

## NJA 実行結果（都道府県で層化した564件）

47都道府県から各12件を等間隔に抽出したサンプル。
上のランダム1000件が北海道と東北に偏るのに対し、こちらは全国のばらつきを拾う。
実際のバッチ CLI を通した出力を集計したもの。

| `_番地の根拠` | 件数 | 割合 |
| --- | --- | --- |
| 照合済み | 184 | 32.6% |
| 推定 | 63 | 11.2% |
| なし | 317 | 56.2% |

| `_備考` | 件数 | 割合 |
| --- | --- | --- |
| （空） | 247 | 43.8% |
| 地番方式のため対象外 | 243 | 43.1% |
| 住居表示未実施の町字 | 72 | 12.8% |
| 住居表示実施済みだが番地を分解できず | 2 | 0.4% |

ランダム1000件より「なし」が多いのは、地番で運用する地方が相対的に重くなるため。

| タグ | 充填率 |
| --- | --- |
| `addr:province` / `addr:city` / `addr:neighbourhood` | 100% |
| `addr:block_number` | 43.8% |
| `addr:housenumber` | 42.9% |
| `addr:suburb` | 12.1% |
| `addr:county` | 8.0% |
| `addr:quarter` | 6.7% |
| `note` | 20.2% |
| `fixme` | 1.4% |

地番方式243件のうち、番地タグが出たものと `level 8` の座標が出たものはいずれも0件。

住居表示未実施の72件のうち49件（68%、全体の8.7%）で `note` が数字で始まる。
住居表示未実施の区域は地番で運用されているので、この数字は実質的に地番。
そのまま出力する判断をした経緯は設計書に書いてある。

`地割` が `addr:neighbourhood` または `addr:quarter` に入るケースが5件（0.9%）。
表記は `第十三地割字普代`、`8地割`、`第13地割`、`第2地割`、`32地割` と揺れる。

## その他の所見

支号（`rsdt_num2`）は分類 A の428件中0件だった。
`housenumber` の `-` 連結は実データではまず出現しない。

入力データの座標が `0.0` のレコードが12.7%ある。
NJA は代表点を返すので、精度レベルを添えて補完できる。

入力データ自体の誤りもある。
`東京都三鷹市下連雀三鷹市下連雀３－３３－１７` は市名が重複しており、`長野県松本市寿南１ー２５４ー１` は区切りが長音符 U+30FC になっている。
後者は NJA が正規化できている。

## 告示の数字表記が復元できる範囲

`oaza_cho_k`（カナ）が告示の数字表記を保持している。

| 自治体 | 大字に漢数字を含む | うちカナが算用数字 |
| --- | --- | --- |
| 札幌市中央区 | 920 | 920（100%） |
| 帯広市 | 1454 | 1372（94%） |
| 旭川市 | 2475 | 2359（95%） |

判別は正確。
`北十条西` のカナは `キタ１０ジョウニシ` で算用告示、`八千代町` のカナは `ヤチヨチョウ`、`住吉町一条` のカナは `スミヨシチヨウイチジヨウ` で漢数字告示になる。
数詞として書かれるかどうかを区別できている。

一方 `chome` は ABR データ自体が常に漢数字で、告示表記が上流に存在しない。
流山市江戸川台西は表が `4丁目` を期待するが、ABR では `chome: "一丁目"`。
「丁」と「丁目」の区別のみ `chome` が保持している（堺市 = `一丁`）。
