# 正とする仕様: OSM 日本の住所タグ体系

この3つを正とします。

- <https://wiki.openstreetmap.org/wiki/JA:Key:addr:*>
- <https://wiki.openstreetmap.org/wiki/JA:住所>
- [地名のタグ付け方法の例](https://docs.google.com/spreadsheets/d/1aOnXzGhZ8DYn0rSUXbT2C0JACesqfJbdpqiz2Jty8n0/edit)（取得済みスナップショット: [scripts/osm-japan-tagging-examples.csv](../scripts/osm-japan-tagging-examples.csv)）

## タグ体系

`*` は地域の体系によって省略されえます。

| タグ | 対応する住所要素 | admin_level |
| --- | --- | --- |
| `addr:country` | `JP` 固定 | |
| `addr:province` | 都道府県 | 4 |
| （対応キーなし） | 振興局 | 5 |
| `addr:county` * | 郡 | 6 |
| `addr:city` | 市 / 特別区（東京23区） / 町 / 村 | 7 |
| `addr:suburb` * | 区（政令指定都市の区） | 8 |
| `addr:quarter` * | 大字。この下の字名が必須である場合にのみ使用 | 9 |
| `addr:neighbourhood` * | 町 / 字 / 丁 / 丁目 | 10 |
| `addr:block_number` * | 街区符号 / 番 / 番地 / 地番。無番地の場合は `無番地` | |
| `addr:housenumber` * | 住居番号 / 号 / 支号 / 枝番号 | |
| `addr:housename` * | 複合住宅・施設の名称 | |
| `addr:room` * | 部屋番号 | |
| `addr:floor` * | 階層 | |

## 2つの番号体系

JA:住所 より。番地部分の解釈が体系で変わります。

街区符号方式（住居表示実施済み）では、`addr:neighbourhood` に「○丁目」があり、続く `addr:block_number` が街区符号、`addr:housenumber` が住居番号になります。

地籍からの番号転用方式（地番）では、`addr:neighbourhood` は町・字で、`addr:block_number` が番地・地番、`addr:housenumber` が枝番号になります。

`2-24-3` のような略記からどちらか判別する方法について、wiki は「1つめの数字が2桁以上ならかなり高い確率で地番」というヒューリスティクスを挙げています。
本ツールではこれを使いません。
NJA が `metadata.rsdt` と `metadata.chiban` のどちらを返すかで体系が確定するので、数字の桁数を数える必要がありません。

## 特殊ケース

wiki が明記しているものです。

| ケース | 扱い |
| --- | --- |
| 無番地 | `addr:block_number` に `無番地` と書く |
| 京都の通り名 | 街路名を含む住所は `addr:full` に格納し、他の階層も埋める |
| 北海道の条丁目 | 条と丁目をまとめて町名として `addr:neighbourhood` に入れる |

## NJA との対応

`scripts/compare-sheet.ts` でスプレッドシート全40件を NJA v3.1.3 に流して突き合わせた結果です。

### quarter と neighbourhood は機械的に決まる

`metadata.machiAza` の3フィールドで場合分けするだけで、表の期待値とほぼ全件一致します。

| NJA の状態 | `addr:quarter` | `addr:neighbourhood` |
| --- | --- | --- |
| `chome` あり | （空） | `oaza_cho` + `chome` |
| `koaza` が丁目の続き | （空） | `oaza_cho` + `koaza` |
| `koaza` あり | `oaza_cho` | `koaza` |
| どちらもなし | （空） | `oaza_cho` |

2行目は、意味的には丁目である文字列が `koaza` に入るケースへの対応です。
`南郷通十四丁目南` は ABR では `oaza_cho=南郷通` と `koaza=十四丁目南` になります。
丁目のあとに方角が付くため、「数字 + 丁目」の形しか受けない `chome` フィールドに入らないためで、ABR のスキーマ制約に対する妥当な回避です。
そのまま分割すると wiki の「条と丁目をまとめて町名として `addr:neighbourhood` に入れる」という北海道の規則に反します。
判定は `koaza` が `^[一二三四五六七八九十百千0-9０-９]+丁目?[北南東西]?$` に一致するかどうかで、`字方八丁` のような地名は該当しません。

表が「例外ルール」「特殊な例外」と注記したケースも、NJA のフィールド構成がそのまま正解になっています。

松戸市北松戸三丁目について、表は「厳密には大字北松戸・小字三丁目だが例外ルールで neighbourhood」と書いています。
NJA は `chome = 三丁目` として返すので、上表で自然に一致します。

郡山市安積町柴宮東について、表は「特殊な例外」と注記しています。
NJA は `oaza_cho = 安積町` と `koaza = 字柴宮東` を持っており一致します。

松戸市南花島中町について、表の判断には「?」が付いています。
NJA も `oaza_cho = 南花島中町` の一体なので一致します。

### 決定: 「大字」「字」の表記は残す

NJA はデータ上の表記をそのまま返します（`大字藤崎`、`字西村井`）。
この接頭辞は除去せず、そのまま出力します（2026-08-21 決定）。

結果としてスプレッドシートの期待値とは差が出ます。

| 住所 | 本ツールの出力 | 表の期待値 |
| --- | --- | --- |
| 藤崎町藤崎西村井 | quarter=`大字藤崎` / neighbourhood=`字西村井` | `藤崎` / `西村井` |
| 郡山市北畑 | neighbourhood=`字北畑` | `北畑` |
| 流山市鰭ケ崎 | neighbourhood=`大字鰭ケ崎` | `鰭ケ崎` |
| 長野市若里 | neighbourhood=`大字若里` | `若里` |

表にも `南郷大字中野` のように接頭辞を保持する例があり、コメントに「「大字」を途中に含む例（省略できない）」と書かれています。
除去する方針を採ると「先頭のみ剥がす」という例外規則が必要になります。
残す方針ならその例外は不要になります。

### 丁目の数字表記は大字側からのみ復元できる

`chome` は ABR データ自体が常に漢数字で、告示の表記は上流に存在しません。
一方 `oaza_cho_k`（カナ）は告示の数字表記を保持しています。
そこで大字のカナに算用数字が含まれる場合は、大字と同レコードの丁目の両方を算用数字にします。

これで大字に数字を含む地域は表と一致します。

| 住所 | カナ | 出力 | 表の期待値 |
| --- | --- | --- | --- |
| 帯広市西19条南42丁目 | `ニシ１９ジョウミナミ` | `西19条南42丁目` | 一致 |
| 千代田区永田町一丁目 | `ナガタチョウ` | `永田町一丁目` | 一致 |

大字に数字を含まない地域は手がかりがなく、漢数字になります。

| 住所 | 出力 | 表の期待値 |
| --- | --- | --- |
| 流山市江戸川台西4丁目 | `江戸川台西四丁目` | `江戸川台西4丁目` |
| 堺市堺区市之町西1丁 | `市之町西一丁` | `市之町西1丁` |
| 横浜市鶴見区朝日町1丁目 | `朝日町一丁目` | `朝日町1丁目` |
| 横浜市旭区二俣川1丁目 | `二俣川一丁目` | `二俣川1丁目` |

「丁」と「丁目」の区別は `chome` の値が保持しているので、変換は数字部分だけを触ります（堺市 = `一丁`）。

### 残る不一致

| 住所 | 内容 |
| --- | --- |
| 長野市大字鶴賀権堂町 | 表は quarter=`鶴賀` / neighbourhood=`権堂町`。NJA は `oaza_cho=大字鶴賀` のみを返し、権堂町は `other` に残る。登記のみで使われる通称地名 |
| 龍ケ崎市寺後 | 表は neighbourhood=`寺後`。NJA は `machiAza` を `{machiaza_id: '0000000'}` のプレースホルダで返すため町字名が1つも取れず、`other=寺後` になる |
| 久慈市夏井町夏井第3地割 | 表は「第○地割は place に入れるのは不適」として neighbourhood=`夏井町夏井` とし、`3-57-1` を番地側に含める。NJA は `koaza=第3地割` を返すので、上表の規則をそのまま当てると quarter=`夏井町夏井` / neighbourhood=`第3地割` になり食い違う |
